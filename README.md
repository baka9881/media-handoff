# 影音接播

Chrome 與 Edge 擴充功能。在同一個瀏覽器的兩個分頁分別播放音樂和影片。影片開始時，擴充功能會暫停正在播放的音樂。等影片暫停、播完或關閉，音樂就從原進度接著播。

## 安裝

1. [下載安裝用 ZIP](https://github.com/baka9881/media-handoff/releases/latest/download/media-handoff.zip)，右鍵選「解壓縮全部」。
2. 在 Chrome 的網址列輸入 `chrome://extensions`，或在 Edge 輸入 `edge://extensions`。
3. 打開「開發人員模式」，點「載入未封裝項目」或「載入解壓縮的擴充功能」。選取剛解壓縮的資料夾，也就是打開後能直接看見 `manifest.json` 的那一層。可以從檔案總管複製這個資料夾的路徑，再貼到選取視窗的網址列。
4. 重新整理已開著的音樂和影片分頁。可以從工具列的擴充功能選單釘選「影音接播」。

從這個儲存庫取得原始碼時，選取 `extension` 資料夾即可載入。

## 使用

- **YouTube Music** 會自動辨識。用一般 **YouTube** 聽歌時，在音樂分頁點「影音接播」，打開「將此分頁當作音樂」。換到新的音樂分頁或重開瀏覽器後，請再指定一次。
- 音樂只會在其他影片都停下後接播。擴充功能只接播由它暫停的音樂，並略過播放器設為靜音的影片。
- 想暫時停用時，關閉「自動暫停與接播」。
- 工具列圖示顯示 `!` 時，點開面板查看是播放中的分頁未連線，還是音樂沒有成功暫停。重新整理未連線的分頁後，可以按「重新檢查」。

## 適用範圍與網站權限

支援使用標準 HTML 音訊及影片播放器的網頁。少數自訂播放器可能不適用。如果瀏覽器擋下自動接播，回到音樂分頁按播放即可。

擴充功能透過網站存取權限讀取播放器的播放狀態，並操作暫停與播放。分頁狀態與設定都保留在本機瀏覽器。
